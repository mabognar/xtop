# xtop
System monitor for the terminal. Fast, informative, and easy to use. Sorting of processes by id, name, 
cpu usage, and memory usage. 
Search/filter by process name or id. Theme support, update notifications. 
Works in Linux, macOS, Windows, and BSD.

## Download
For macOS and Linux (.deb) binaries, go to
````
https://github.com/mabognar/xtop/releases/latest
````

## Build
In suitable directory, run
```
git clone https://github.com/mabognar/xtop
cd xtop
cargo install --path .
xtop
```
Alternatively, 
```
cargo install xtop
```
